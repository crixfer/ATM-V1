Este sistema de cajeros automaticos es un projecto en el cual estoy trabajando para aprender a utilizar C# de manera eficiente,
tomando en cuenta todo lo necesario para que funcione y cumpla con los requisitos del cliente.

En el mismo, he agregado lo aprendido hasta el momento y he adquirido conocimientos que me ayudaran en el futuro con proyectos similares.

En este sistema, el usuario podra sollicitar balance, modificarlo con depositos o retiros, validar numero de cuenta, agregar nombre completo, etc.

Ha sido un ejercicio interesante y que me ha permitido lograr funciones que antes no conocia.
El proyecto seguira creciendo mientras siga aprendiendo.

To be continue.
